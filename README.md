# 英灵神殿弹反与生存计算器

在线使用：https://yuren1024.github.io/valheim-calculator/

本项目通过 GitHub Pages 从 `main` 分支根目录发布，更新 `index.html` 后自动重新部署。

用 Chrome、Edge 或 Safari 打开同目录的 `index.html` 即可使用。HTML 内置全部数据和程序，无需安装、联网或登录。

## 已实现

- 数据快照：Valheim 1.0.20，Steam build 25909357，2026-10-22 整理。
- 96 个具有攻击数据的生物条目、295 条单次攻击数据，包含首领阶段和特殊变体。
- 97 种食物、129 件穿戴装备、161 件手持装备。怪物、食物、装备均使用“中文(英文)”形式。
- 三份不同食物，自动计算生命、耐力及原质上限；每份食物可设置剩余时间。
- 分栏选择装备、独立选择等级、21 组整套配装预设、潜能强化等级、抗性和套装效果。
- 饰品未触发／已触发两种状态。瞬间回复不作为生命上限或伤害减免。
- 五档原版战斗难度、自定义敌人伤害倍率、星级、附近玩家人数。
- 对比不防御、持续举盾和弹反；区分弹反成立、自身踉跄、敌人踉跄与死亡。
- 展示满伤及伤害波动范围、完整结算步骤、反推所需生命上限和全招式对照。
- 本地保存多套搭配、记住上次状态、导入导出配置 JSON、深浅色主题、手机布局。

## 开始使用

1. 选择三份食物。默认是示例三餐：香肠、鹿肉炖锅、熟鱼肉，刚吃下时生命上限170。
2. 选择穿戴与手持装备。若希望使用装备自动合计的护甲，关闭“身体护甲：手动覆盖”。
3. 输入当前生命、当前耐力、格挡技能和已有踉跄值。“回满”按钮才会把当前资源设为上限；换食物不会凭空回满资源。
4. 选择对手、招式、战斗难度、星级和附近人数。
5. 查看右侧结论和下方全部招式。默认使用满伤判断，不把偶尔成功说成稳定成功。

初始案例使用无星恶骨、噩梦、格挡10、3级黑金属盾、170生命上限、67手动护甲。67护甲未推断为你的实际穿戴装备；你可以自行关闭手动覆盖后配装。

“安全弹反”表示：在已经正确抓准时机、正面受击的前提下，弹反成立、自身不踉跄并存活，不等于无伤。

## 计算范围

- 第一版以单次命中为单位。连击、弹幕和吐息中的每一击可以分别查看，不模拟整个攻击序列、动画中断或中途恢复。
- 火焰、毒素单列潜在持续伤害。持续伤害后的死亡判定以不治疗、不解除效果为条件，不模拟已有持续效果、重复叠加或精确跳伤时序。
- 潮湿燃烧、保护之杖护盾等未完整模拟的效果会显示“待核实”，不会输出安全结论。
- 不模拟地形、多目标分摊、耐久耗尽、环境伤害和实际按键时机。
- 进度筛选依据材料来源群系，不替代完整的配方与工作站解锁校验。
- 本地存档属于当前浏览器和文件地址。移动文件或更换浏览器前，请导出 JSON 备份。

## 验证与来源

已通过24组核心计算检查，并遍历295条内置攻击在不同难度、星级和防御方式下的数值边界。浏览器检查包含食物衰减、防重复、装备等级、抗性、套装与饰品、配装冲突、配置保存和导入导出、离线运行以及320～1440像素布局。

基础数值和本地化名称整理自 [Valheim Database](https://valheimdb.com/) 公布的游戏文件数据；结算顺序同时参考其[格挡计算说明](https://valheimdb.com/tools/block-calculator)及 [Corpus 的游戏机制资料](https://corpus.gg/games/valheim/mechanics/blocking)。每个类别的来源链接也列在页面底部。

这是非官方工具，游戏数据属于 Iron Gate AB / Coffee Stain。
